Purpose
-------
Static Admin UI (admin.html + css/admin.css + js/admin.js) so Jorge can
permanently add/edit/delete garage vehicles by committing to GitHub himself
while bots stay idle. No server, no database, no baked secrets.

How to use
----------
1. Open admin.html (obscurity: passphrase `vb-garage`, or `?key=vb-garage`).
   Gate is NOT real security — the GitHub PAT is auth.
2. Create a fine-grained GitHub PAT:
   - Resource owner: 01ls1z28-coder
   - Repository access: only `forcemetric-web`
   - Permissions: Contents = Read and write
   - Optional: Pull requests = Read and write (to open PRs)
   - Short expiry (hours–days) recommended
3. Paste PAT → Save to session (sessionStorage only; clears on tab close).
4. Load garage from main → search / edit / add / clone / delete.
5. Commit → creates NEW branch `review/vb-garage-admin-YYYYMMDD-HHMM` (UTC)
   from current main tip via Git Data API (blob → tree → commit → create ref).
   Never updates main. Never triggers Pages live deploy from admin.
6. UI shows branch name + commit SHA + note:
   “Seraph must clear before Merovingian deploys.”
